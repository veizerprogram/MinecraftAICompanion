# Minecraft AI Companion — Chatty (Forge 1.20.1)

Це мод із ШІ-напарником Chatty для одиночного Survival та локального тестування.

## Уже реалізовано
- окрема людська сутність Chatty;
- прив'язка до власника та збереження власника у світі;
- слідування за власником і команда очікування через Shift + ПКМ;
- захист від ворожих монстрів;
- реакція на базові українські команди без API;
- історія розмов власника та окрема локальна пам'ять почутих повідомлень інших гравців; повідомлення інших гравців не додаються до контексту зовнішнього AI;
- збір контексту виживання: координати, біом, час доби, погода, здоров'я, голод, інвентар, броня, рухи гравця, істоти, монстри та предмети на землі поблизу;
- необов'язковий асинхронний AI-мозок через OpenAI-compatible Chat Completions API;
- AI може відповідати на повідомлення власника та обирати дії: FOLLOW, RETREAT, WAIT, GUARD, EXPLORE або NONE;
- періодична автономна оцінка ситуації з налаштовуваним інтервалом.

## Підключення AI
Після першого запуску Forge створить файл:

`config/ai_companion-common.toml`

У секції `chatty_ai` є параметри:
- `enabled` — увімкнути AI;
- `apiUrl` — повна адреса сумісного Chat Completions endpoint;
- `apiKey` — приватний ключ провайдера;
- `model` — назва моделі;
- `autonomyIntervalSeconds` — інтервал автономної оцінки (за замовчуванням 300 секунд).

**Не публікуй API-ключ, не надсилай його в чат і не додавай конфіг із ключем у GitHub.** Виклики зовнішнього AI-провайдера можуть мати оплату. Перед налаштуванням платного API узгодь це з батьками/опікунами та перевір умови й тарифи провайдера. Мод локально запам'ятовує повідомлення, які бачить Chatty у завантаженій частині виміру. Повідомлення інших гравців зберігаються окремо й не додаються до контексту зовнішнього AI. Провайдеру надсилаються повідомлення власника Chatty та обмежений ігровий контекст, потрібний для відповіді.

Якщо ключ не заданий, мод використовує локальні базові команди й не робить мережевих AI-запитів.

## Збірка
Потрібна Java 17 і Forge 1.20.1 (47.x). GitHub Actions збирає JAR автоматично після змін у гілках `main` та `chatty-autonomy-v2`. Завантаж artifact `ai-companion-forge-1.20.1` з успішного запуску Actions.

## Тестування
Створи Chatty командою:

`/summon ai_companion:companion`

Натисни ПКМ, щоб прив'язати його до себе. Shift + ПКМ перемикає очікування/слідування.


## Команди Chatty

У чаті власника Chatty розпізнає команди українською та англійською:
- «стій», «почекай», «охороняй», «stay here» — залишитися на місці;
- «йди за мною», «пішли зі мною», «follow me», «come here» — супроводжувати власника;
- «досліди околиці», «розвідай», «explore», «look around» — почати коротку розвідку.

Команди обробляються локально перед запитом до зовнішнього AI, тому базові накази працюють і без API-ключа. Якщо власник звертається до Chatty вільним текстом, але зовнішній AI не налаштований, Chatty повідомляє про це замість мовчання.
