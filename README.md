# Minecraft AI Companion — початкова версія 0.1.0

Це стартовий проєкт мода для **Minecraft 1.20.1 + Forge 47.x**.

## Що вже закладено
- окрема сутність Chatty;
- 30 HP, швидкість, шкода та броня;
- приручення/прив'язка до першого гравця, який натисне ПКМ;
- слідування за власником;
- перемикання режиму «стояти тут» через Shift + ПКМ;
- атака ворожих монстрів та відповідь на отриману шкоду;
- збереження власника й режиму після перезапуску світу.

## Що ще НЕ готове
Голос, підключення до AI API, довготривала пам'ять, повноцінний інвентар, добування ресурсів і будівництво — наступні етапи. Це не готовий фінальний мод.

## Важливо
Для Minecraft 1.20.1 потрібна **Java 17** для розробки/Gradle. Якщо у тебе встановлена лише Java 21, краще встановити JDK 17 і вибрати її в налаштуваннях IDE.

## Як відкрити
1. Розпакуй ZIP у папку, наприклад `D:\MinecraftMods\AICompanion`.
2. Відкрий цю папку у IntelliJ IDEA або Eclipse як Gradle-проєкт.
3. Дочекайся завантаження ForgeGradle залежностей (потрібен інтернет).
4. Запусти Gradle task `runClient`.
5. Після перевірки збери мод командою `gradlew build`. Готовий JAR буде в `build/libs`.

## Тестування в грі
Після успішного запуску створи сутність командою:
`/summon ai_companion:companion`

Натисни ПКМ по Chatty, щоб стати його власником. Shift + ПКМ перемикає режим очікування/слідування.

## Примітка про текстуру
Потрібно додати PNG-текстуру персонажа за адресою:
`src/main/resources/assets/ai_companion/textures/entity/chatty.png`

Для першого тесту можна скопіювати сумісну 64x64 текстуру Minecraft-персонажа й назвати її `chatty.png`.


## Автоматичне збирання через GitHub (без встановлення IDE)
1. Створи порожній репозиторій на https://github.com/new (назва, наприклад, `MinecraftAICompanion`).
2. Розпакуй ZIP на комп'ютері.
3. На сторінці репозиторію натисни **Add file → Upload files**.
4. Перетягни ВСІ файли й папки з розпакованого проєкту, включно з прихованою папкою `.github`. Важливо: завантажуй вміст папки проєкту, а не сам ZIP.
5. Натисни **Commit changes**.
6. Відкрий вкладку **Actions**. Дочекайся завершення workflow **Build Minecraft AI Companion**.
7. Відкрий успішний запуск і завантаж Artifact `ai-companion-forge-1.20.1`. Усередині буде JAR для папки `mods`.

Якщо GitHub не показує workflow, перевір, що `.github/workflows/build.yml` справді завантажився. Якщо збірка впаде, надішли скриншот червоного повідомлення з Actions.
